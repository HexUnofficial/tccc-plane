Make it watchable scales the turn, altitude, speed and aircraft to the run you have drawn — the shipped numbers are a 400 m banner up 2.5 km of the Thames, and on a short run they give a nine-second lap you cannot follow. Deployed flight path puts the shipped circuit back around the pins wherever they are, keeping the bearing you have drawn — that one belongs to the river you are pointing at, not to the deployment. Neither touches the deployment: these sliders only decide what goes in the link and the QR, and the installation changes only when you paste the two Ship it boxes.

Compass offset only matters if the aircraft flies at an angle to the run you drew. Add &north=90 to the link on site and watch: if the path swings onto the river, the phone's magnetometer is that far out, and this slider carries the correction into the QR. Try −90 as well — the sign depends on the device.

Preview anywhere Open for real

Preview anywhere adds ?sim=1, which fakes the GPS and the compass: the circuit appears in front of you at the Watched from distance, wherever you are standing. It still needs a phone — the camera is a real one — but not the site. Open for real is the link in the QR: actual GPS and compass, so it only shows anything standing at the anchor.

Worth knowing before you test in the garden: the anchor is the middle of the run, so scanning the QR at home stands you inside a — circuit. The aircraft is overhead for a few seconds of each lap and hundreds of metres away for the rest of it, with the arrow swinging round after it. Shorten the run and drop the speed to see it properly on a small site, or use Preview anywhere.

An authoring tool, but it is built and deployed by default, so anyone who finds /setup.html can generate a link that moves the aircraft. It only emits links — nothing here writes to the scene. Build with EXCLUDE_SETUP=1 to leave the page out, or set LOCKED in src/location.ts to make the AR page ignore placement set from a URL — which also stops these links working, so ship the values with the Ship it snippet first.
